# The 8-bit Catalog

<br>

The 8-bit Catalog is a searchable library of games released for the Nintendo Entertainment System. The React framework Next.js is used for both frontend and backend. Files are persisted in Supabase storage. Drizzle communicates directly with a Supabase Postgres database for storing metadata. Better Auth is used to handle things related to auth. Zod and drizzle-zod are used for data validation. This project is a work in progress.
